# Request for existing responsive-membrane measurements

Draft to Michael Hickner. Public work address and its institutional source are listed in PARTNER_TARGETS.md. No message has been sent.

Subject: Existing transport data for a responsive-membrane control test

Professor Hickner,

I'm developing AutoBalance, an open computational project testing whether state-responsive membrane transport can outperform fixed transport and timed actuation under unexpected concentration disturbances.

Your work on redox-responsive viologen anion-exchange membranes looks directly relevant. I currently have software access and am seeking a research partner for the first experimental feasibility check.

Could your group share existing concentration-time data at two or more redox states, together with membrane area/thickness, reservoir volumes, electrolyte composition, and any gate-step voltage/current traces? Opening and closing response times would be especially useful. Data from the membrane's demonstrated chemistry would be a suitable starting point.

I would use those measurements to fit transport and response dynamics, reserve separate runs for validation, and report whether the control benefit survives the measured constraints. The current model uses hypothetical transport parameters and does not demonstrate a working battery or energetic autonomy.

Code and assumptions: https://github.com/mehtaarnav/AutoBalance

If existing data are unavailable, would a short discussion about a minimal two-reservoir experiment be possible?

Arnav Mehta
