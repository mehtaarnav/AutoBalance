# Wang et al. released source data

Downloaded from the authors' [Figshare deposit](https://doi.org/10.6084/m9.figshare.28938164), October 7, 2026. Attribution: Zhenyu Wang and coauthors, *Balanced-state electrolytes overcome crossover in vanadium redox flow batteries*, Nature Communications (2026), DOI [10.1038/s41467-026-70872-8](https://doi.org/10.1038/s41467-026-70872-8).

The deposit declares [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). These two files retain that license, independently of the repository's MIT license. Local filenames were changed; file contents were not.

- `figure2a_author_script.txt`: original `Script for Fig. 2a.txt`, [download](https://ndownloader.figshare.com/files/59881886). Read as source; do not execute unreviewed downloads.
- `figure2.xlsx`: original `Fig. 2.xlsx`, [download](https://ndownloader.figshare.com/files/59881892).

Figure 2a is computed data, not a responsive-membrane experiment. Figure 2e contains experimentally reported concentration endpoints. Neither supplies a gate response time or gate work. The released script does not specify the units of its four coefficients; AutoBalance uses their ratios only.
